# ICS Mongolia Static Website

Static website for Industrial Control Solutions LLC — deployed to Cloudflare Workers.

## Deployment

Every push to `main` triggers the GitHub Action (`.github/workflows/deploy.yml`), which:

1. Runs `npm ci` to install dependencies
2. Runs `node build.js` to regenerate `en/index.html` and `mn/index.html` from `content/*.yml`
3. Runs `npx wrangler deploy` to publish to Cloudflare Workers

Takes about 1–2 minutes end to end. No manual steps required.

For manual deploys and troubleshooting see `DEPLOYMENT-GUIDE.md` in the parent directory.

## Routes

- `/` — redirects immediately to `/mn/` (Mongolian is the default language)
- `/en/` — English website
- `/mn/` — Mongolian website

## Editing Content

`content/en.yml` and `content/mn.yml` are the **single source of truth** for all page text.
**Do not edit `en/index.html` or `mn/index.html` directly** — they are generated by `build.js`
and will be overwritten on the next push.

After editing a YAML file locally, regenerate the HTML:

```bash
npm run build
```

## Local Development

```bash
npm install          # first time only
npm run build        # regenerate HTML from content/*.yml
python3 -m http.server 4173
# Visit http://localhost:4173/mn/ or http://localhost:4173/en/
```

## Pages CMS

Pages CMS is configured in `.pages.yml`. CMS edits commit directly to `content/en.yml` or
`content/mn.yml`, which triggers the GitHub Action and automatically rebuilds and redeploys
the site. No manual HTML editing is needed.
